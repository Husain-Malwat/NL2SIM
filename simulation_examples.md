## Example 1   Permalloy Domain Wall Motion (Field-Driven)

### Input
```
Simulate domain wall motion in a 512×128×5nm Permalloy nanowire under a
10mT field pulse along +x, saving magnetisation every 100ps over 10ns.
```

### Extracted IR
```json
{
  "category": "field_driven",
  "material": {
    "name": "Permalloy",
    "Msat_Am": 800000,
    "Aex_Jm": 1.3e-11,
    "alpha": 0.01
  },
  "geometry": { "shape": "rectangle", "size_x_nm": 512, "size_y_nm": 128, "size_z_nm": 5 },
  "domain":   { "nx": 512, "ny": 128, "nz": 1, "dx_m": 1e-9, "dy_m": 1e-9, "dz_m": 5e-9,
                "exchange_length_nm": 5.69, "cell_size_nm": 1.0 },
  "physics":  { "use_exchange": true, "use_demag": true, "use_zeeman": true },
  "excitation": { "type": "pulse", "B_T": 0.01, "direction": "+x", "pulse_ns": 10.0 },
  "initialization": { "type": "two_domain", "direction": "+x" },
  "solver": { "mode": "relax_then_run", "t_total_s": 1e-8, "dt_save_s": 1e-10 }
}
```

### Generated Script
```
// ─────────────────────────────────────────────────────
// MuMax3 simulation  |  generated by NL2Sim
// Category  : field_driven
// Material  : Permalloy
// Geometry  : 512 × 128 × 5 nm
// ─────────────────────────────────────────────────────

// Grid
SetGridsize(512, 128, 1)
SetCellsize(1.0000e-09, 1.0000e-09, 5.0000e-09)

// Material
Msat  = 8.0000e+05   // 800 kA/m
Aex   = 1.3000e-11   // 13.0 pJ/m
alpha = 0.01

// Initial magnetisation
m = twoDomain(1, 0, 0, -1, 0, 0)  // head-to-head domain wall

// Find equilibrium before dynamics
relax()

// Excitation
// Pulse: 10.0 mT, 10.0 ns duration
B_ext = vector(1.0000e-02 * pulse(1.000e-09, 1.000e-08, 1.000e-09),
               0.0000e+00 * pulse(1.000e-09, 1.000e-08, 1.000e-09),
               0.0000e+00 * pulse(1.000e-09, 1.000e-08, 1.000e-09))

// Outputs
autosave(m, 1.000e-10)   // every 100 ps
tableautosave(1.000e-10)
tableadd(E_total)
tableadd(E_exch)
tableadd(E_demag)

// Run dynamics
run(1.0000e-08)   // 10.0 ns total
```

### Expected Physics Output
If this script were run in MuMax3, we would expect:

**After relax()**: A Bloch-type domain wall forms at the centre of the nanowire.
mz averages near zero; mx averages near 0 (equal +x and -x domains).
Total energy converges to ~3.2 × 10⁻¹⁷ J.

**After field application**: The 10 mT pulse drives the domain wall in the +x direction.

Expected domain wall velocity: ~150 m/s (below Walker breakdown, which for Permalloy
occurs around 180 m/s at 10 mT in this geometry).

The mz component shows the characteristic oscillation at the Walker breakdown frequency.
Total simulation produces 100 magnetisation snapshots and a table.txt with 100 rows.

**Quantitative predictions**:

| Quantity | Expected Value | Physical Basis |
|---------|---------------|----------------|
| DW velocity | ~150 m/s | Below Walker breakdown for Permalloy at 10mT |
| Walker breakdown field | ~18 mT | For Permalloy with α=0.01 |
| Relaxation time | ~0.5 ns | α × (LLG precession frequency)⁻¹ |
| Exchange energy after relax | ~3.1×10⁻¹⁷ J | Standard DW width ~20nm in Permalloy |
| DW displacement in 10ns | ~1.5 μm | v × t ≈ 150 m/s × 10 ns |

## Example 2   CoFeB Skyrmion Nucleation (DMI)

### Input
```
CoFeB disk 200nm diameter 5nm thick with interfacial DMI=2mJ/m2 and
PMA Ku1=800kJ/m3. Nucleate a skyrmion and relax to stable state.
```

### Generated Script
```
// ─────────────────────────────────────────────────────
// MuMax3 simulation  |  generated by NL2Sim
// Category  : dmi_skyrmion
// Material  : CoFeB
// Geometry  : 200 × 200 × 5 nm
// ─────────────────────────────────────────────────────

// Grid
SetGridsize(128, 128, 1)
SetCellsize(1.5625e-09, 1.5625e-09, 5.0000e-09)

// Geometry
SetGeom(cylinder(1.0000e-07, 5.0000e-09))

// Material
Msat  = 1.1000e+06   // 1100 kA/m
Aex   = 2.0000e-11   // 20.0 pJ/m
alpha = 0.01
Ku1   = 8.0000e+05   // uniaxial anisotropy constant
anisU = vector(0, 0, 1)  // easy axis along z (perpendicular)
Dind  = 2.0000e-03   // interfacial DMI

// Initial magnetisation
m = uniform(0, 0, 1)
m.setInShape(circle(1.000e-08), uniform(0, 0, -1))

// Find equilibrium before dynamics
relax()
save(m)  // save equilibrium magnetisation
```

### Expected Physics Output

**Parameter check before running**:
- Quality factor Q = Ku1 / (μ₀/2 × Msat²) = 800e3 / (4π×10⁻⁷/2 × (1100e3)²) ≈ 1.05
  Q > 1 means PMA is strong enough to support perpendicular magnetisation ✓
- DMI stability: D/D_c where D_c ≈ 4/π × sqrt(A×Ku) ≈ 4.2 mJ/m²
  Our D = 2.0 mJ/m² < D_c → skyrmion-compatible regime ✓
- Skyrmion radius estimate: r_sk ≈ π/4 × sqrt(A/Ku) × (D/D_c) ≈ 18 nm

**After relax()**: A stable Néel-type skyrmion forms with:
- Topological charge Q_topo = −1 (confirmed by ext_topologicalcharge)
- Skyrmion radius ~18–20 nm
- Core pointing in −z direction, surrounded by +z background

| Quantity | Expected Value |
|---------|---------------|
| Topological charge after relax | −1.0 |
| Skyrmion radius | ~18 nm |
| Total energy | ~8.5 × 10⁻¹⁸ J |
| Exchange energy | ~1.2 × 10⁻¹⁸ J |
| Anisotropy energy | ~2.1 × 10⁻¹⁸ J |
| DMI energy | ~−4.8 × 10⁻¹⁸ J (negative   stabilises skyrmion) |

### Input

```
YIG disk 500nm diameter 10nm thick. Apply a sinc pulse field and compute
the spin-wave spectrum via FFT. Temperature 0K.
```

```
SetCellsize(1.9531e-09, 1.9531e-09, 1.0000e-08)

// Geometry
SetGeom(cylinder(2.5000e-07, 1.0000e-08))

// Material
Msat  = 1.4000e+05   // 140 kA/m
Aex   = 3.7000e-12   // 3.7 pJ/m
alpha = 0.0002       // ultra-low damping

// Initial magnetisation
m = uniform(1, 0, 0)

// Find equilibrium before dynamics
relax()

// Excitation
// AC sinusoidal excitation at 5.0 GHz
B_ext = vector(1.0000e-04 * sin(2*pi*5.0000e+09*t), 0, 5.0000e-02)

// Outputs
autosave(m, 1.000e-11)   // every 10 ps (needs fine sampling for GHz)

tableadd(E_total)
tableadd(E_exch)

// Run dynamics
```


### Expected Physics Output

At 300K, thermal fluctuations add stochastic noise to the LLG equation.
The magnetisation will not follow a smooth trajectory   instead it fluctuates
around the equilibrium direction set by the applied field.

**Expected behaviour**:
- ⟨mx⟩ ≈ 0.95–0.99 (field aligns magnetisation but thermal noise reduces it)
- Fluctuation amplitude: δm ≈ sqrt(k_B T / (μ₀ Msat V)) × some factor ≈ 0.01–0.05
- Energy fluctuations: δE/E ≈ k_B T / E_Zeeman ≈ 0.004 (less than 1%)

**Note**: Each run at 300K produces a DIFFERENT result due to the random thermal field.

## Example 5   Multi-Region Simulation (Permalloy/CoFeB Interface)

### Input
```
Simulate a 512×128×5nm rectangle with Permalloy on the left half and
CoFeB on the right half. Apply a field and watch the interface dynamics.
```

### Generated Script
```
// ─────────────────────────────────────────────────────
// MuMax3 simulation  |  generated by NL2Sim
// Category  : multi_region
// Material  : Permalloy
// Geometry  : 512 × 128 × 5 nm
// ─────────────────────────────────────────────────────

// Grid
SetGridsize(512, 128, 1)
SetCellsize(1.0000e-09, 1.0000e-09, 5.0000e-09)

// Material (Region 0   Permalloy, left half)
Msat  = 8.0000e+05   // 800 kA/m
Aex   = 1.3000e-11   // 13.0 pJ/m
alpha = 0.01

// Region 1   CoFeB, right half
defRegion(1, xrange(2.5600e-07, 5.1200e-07))
MsatRegion(1) = 1.1000e+06
AexRegion(1)  = 2.0000e-11
alphaRegion(1) = 0.005

// Initial magnetisation
m = uniform(1, 0, 0)

// Find equilibrium before dynamics
relax()

// Excitation
// DC field: 10.0 mT along x
B_ext = vector(1.0000e-02, 0.0000e+00, 0.0000e+00)

// Outputs
autosave(m, 1.000e-10)   // every 100 ps
tableautosave(1.000e-10)
tableadd(E_total)
tableadd(E_exch)
tableadd(E_demag)

// Run dynamics
run(5.0000e-09)   // 5.0 ns total
```

### Expected Physics Output

**After relax()**: The interface region shows a smooth transition in exchange
coupling between the two materials. A slight spin texture forms at the boundary
due to the different exchange stiffnesses.

**During field-driven dynamics**:
- The Permalloy region responds faster (lower Msat means higher gyromagnetic ratio × field effect)
- The CoFeB region follows with a slight phase delay
- Interface spin waves propagate from the excitation source into both regions
